# two-pointers-patterns 配音稿

每幕一个 `## 幕 id`，每行一句配音（即一条字幕）。`# 动作：` 是这句对应的画面；`# +N` 表示这句说完后画面再走 N 秒。
改完运行 `node build.mjs`，重新生成 `assets/beats.js`、`compositions/captions.html` 与 `index.html`。

## 读法
nums → numbers
lo → low
hi → high

## s01
数组占用一段连续的内存，按下标可以直接读写任意一个元素。

代价在删除：从中间删掉一个元素，后面的元素都要向前移动一格。
# 动作：下标 2 的格子标橙、落下消失；后面三个格子依次向左滑一格。

删除 k 个元素要移动 k 轮，总的时间是 n 的平方。
# 动作：数组恢复原状，三个 3 都标橙；上方出现 O(n²)。
双指针的做法是不移动元素：用两个下标标记位置，每个元素只读一次，最多写一次。
# 动作：橙色褪去，O(n²) 换成 O(n)；两个指针标签落在数组两端的下方。

## s03
在有序数组里找两个数，使它们的和等于 10。逐对尝试需要 n 的平方次。
# 动作：数组 1、3、4、6、8、11 出现；右上角 target = 10；几对格子依次闪亮。
让两个指针从两端出发：左指针指向最小的数，右指针指向最大的数。
# 动作：l 落在下标 0，r 落在下标 5；下方算出 1 + 11 = 12。
和是 12，大于 10。11 与最小的数相加都超过目标，与其他数相加只会更大，所以排除 11，右指针左移。
# 动作：算式标出 > 10；11 的格子变灰；r 移到 8。
# +0.6
现在和是 9，小于 10。1 与剩下最大的数相加都不够，所以排除 1，左指针右移。
# 动作：算式换成 1 + 8 = 9，标出 < 10；1 的格子变灰；l 移到 3。
# +0.6
每一步排除一个数，最多 n 步就能找到答案。
# 动作：继续三步：3 + 8 = 11，r 左移；3 + 6 = 9，l 右移；4 + 6 = 10，两个格子点亮。
# +3.4
反转数组、判断回文、盛水最多的容器，都是两个指针从两端向中间收缩。
# 动作：右上角补上题号 344、125 与 11。

## s04
三个数的和为 0：先把数组排序。
# 动作：未排序的数组出现，格子滑动重排成 -4、-1、-1、0、1、2。
# +1.0

这正是对撞指针：左右指针落在右边这一段的两端，向中间收缩。
# 动作：l、r 落在这一段的两端；l 一路右移，没有找到。

排序之后相同的数相邻。指针遇到和上一个相同的数就跳过，结果里便不会出现重复的三元组。
# 动作：i 移到第二个 -1，它与前一个相同，格子变灰，i 直接跳到 0。
外层 n 次，内层对撞 n 步，一共 n 的平方。四数之和再多固定一个数。
