# linked-list-patterns 配音稿

每幕一个 `## 幕 id`，每行一句配音（即一条字幕）。`# 动作：` 是这句对应的画面；`# +N` 表示这句说完后画面再走 N 秒。
改完运行 `node build.mjs`，重新生成 `assets/beats.js`、`compositions/captions.html` 与 `index.html`。

## 读法
prev → previous
cur → current
nxt → N X T

## s01
数组占用一段连续的内存，按下标可以直接访问任意元素。
# 动作：五个格子连成一排，下标 0 到 4 出现；下标 3 的格子直接点亮。
链表的节点分散在内存各处，每个节点保存一个值和一个 next 指针。
# 动作：格子拆开，散到高低不同的位置；第一个节点伸出箭头，标出 val 与 next。
next 指向下一个节点，最后一个节点的 next 为 None。
# 动作：其余箭头依次画出，末尾接上 None。
访问第 k 个节点，只能从 head 出发，沿 next 逐个向后走。
# 动作：节点排成一行；head 标签落在第一个节点，cur 标签逐个向后走三步。
# +1.2
链表的插入和删除不需要移动其他元素，只需修改指针。
# 动作：一根箭头绕过中间的节点，该节点落下消失，其他节点原地不动。
# +0.8

## s02
链表上的操作，最终都是修改某个节点的 next。
# 动作：四个节点的链表出现，箭头依次闪亮。
删除一个节点：让它前一个节点的 next 绕过它，指向它的后一个节点。
# 动作：prev、cur 标签落位；prev 的箭头拱起，越过 cur 接到后一个节点；cur 落下消失，后面的节点靠拢。
# +1.5
插入一个节点需要改两根指针，顺序不能颠倒。
# 动作：新节点出现在链表下方，prev 的箭头闪亮。
如果先让 prev 的 next 指向新节点，就没有指针指向后半段，后半段无法找到。
# 动作：prev 的箭头转向新节点；后半段变灰、飘离，标出“丢失”；随后画面恢复原状。
# +1.6
正确的顺序是先让新节点指向后半段，再让 prev 指向新节点。
# 动作：新节点的箭头接到后半段；prev 的箭头转向新节点；新节点升入行内。
# +0.8
这条规则贯穿所有链表题：修改指针之前，先保存后面的节点。
# 动作：四根箭头依次闪亮，画面下方出现“先保存，再修改”。
# +0.8

## s03
删除节点要用到它的前一个节点，而头节点没有前一个节点。
# 动作：链表 6、1、6、2，值为 6 的节点标橙；prev 落在第二个 6 的前一个节点上，再移到头节点左侧的空位，空位打着问号。
因此删除头节点需要单独处理，代码多出一个分支。
# 动作：链表下方出现专门处理头节点的两行代码。
在头节点前面加一个哑节点 dummy，每个节点便都有了前一个节点。
# 动作：问号换成虚线的 dummy 节点，箭头接到头节点；那两行代码被划掉。
从 dummy 出发，用同一段循环处理所有节点。
# 动作：prev 从 dummy 开始：下一个节点的值是 6 就让箭头绕过它，否则 prev 前进一步，直到末尾。
# +5.6
最后返回 dummy 的 next，即新的头节点。
# 动作：head 标签落在 dummy 后面的节点上，dummy 变淡。
合并两个有序链表时，结果链表的头同样先用 dummy 占位。
# 动作：右上角的题号换成 21，dummy 重新亮起。

## s04
反转链表，就是把每一根 next 指针掉转方向。
# 动作：链表 1、2、3、4 出现，四根箭头依次闪亮。
使用 prev 和 cur 两个指针：prev 初始为 None，cur 指向头节点。
# 动作：链表左侧出现 None，prev 落在上面；cur 落在头节点。
掉转 cur 的指针之前，先用 nxt 保存下一个节点，否则后半段会丢失。
# 动作：代码第一行出现；nxt 标签落在第二个节点；后半段暗一下再恢复。
然后让 cur 的 next 指向 prev。
# 动作：代码第二行；第一根箭头掉头，指向左侧的 None。
最后 prev 和 cur 各前进一步。
# 动作：代码第三、四行；prev 移到第一个节点，cur 移到第二个节点。
重复这四行，直到 cur 为 None。
# 动作：高亮条在四行之间循环三轮，箭头逐根掉头，标签逐步右移。
# +4.2
此时 prev 指向新的头节点。
# 动作：head 标签落在最后一个节点上。
反转链表的一段、K 个一组反转，都是在这四行之外增加边界处理。
# 动作：右上角补上题号 92 与 25，代码框跳动一下。

## s05
链表不能按下标访问，长度也未知；要找中点，可以让两个指针以不同的速度前进。
# 动作：五个节点的链表；中间节点上方打出问号；slow 与 fast 两个标签落在头节点。
slow 每次走一步，fast 每次走两步；fast 到达末尾时，slow 停在中点。
# 动作：代码三行；两个标签按各自的步长前进两轮；fast 到末尾，slow 所在的节点点亮。
# +1.2
找倒数第 k 个节点时，让 fast 先走 k 步，再让两个指针同速前进。
# 动作：标签回到头节点；fast 先走两步，两个标签之间架起“k = 2”的跨度。
两个指针的间隔始终是 k；fast 走出链表时，slow 停在倒数第 k 个节点。
# 动作：两个标签带着跨度一起右移，fast 落到 None，slow 所在的节点点亮。
# +0.6
如果链表中有环，fast 不会走到末尾，而是在环内从后面追上 slow。
# 动作：末尾的 None 消失，最后一个节点的箭头拱回中间的节点；两个标签重新出发，fast 绕环追上 slow。
# +2.6
两个指针相遇，即可判定存在环。
# 动作：相遇的节点点亮并跳动。
# +0.6

## s06
重排链表：把 1、2、3、4、5 排成 1、5、2、4、3，即首尾交替取节点。
# 动作：链表 1 到 5；按 1、5、2、4、3 的次序，节点逐个闪亮，下方依次排出目标顺序。
第一步，用快慢指针找到中点。
# 动作：右上角三个步骤中第一个点亮；slow、fast 走两轮，slow 停在 3。
# +0.6
第二步，从中点之后断开，把后半段反转。
# 动作：4、5 下移成第二行，3 的箭头改指 None；4、5 之间的箭头掉头，两个节点换位，读作 5、4。
# +2.2
第三步，把两段交替合并；每接一个节点之前，同样先保存它的 next。
# 动作：箭头依次改接：1 到 5、5 到 2、2 到 4、4 到 3；第二行升入第一行，排成 1、5、2、4、3。
# +1.4
找中点、反转、改指针：链表题大多是这几个动作的组合。
# 动作：三个步骤全部点亮，箭头依次闪亮，下方出现“先保存，再修改”。
# +1.6
